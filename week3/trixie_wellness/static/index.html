How does Trixie work? +

Trixie routes your input through 3 AI agents, then uses MCP-style tool calls to enrich the response:

StepAgent / ToolJob
1 Emotion Agent Detects your emotion & severity (low / medium / high)
2 Context Agent Identifies the root cause (workload, meetings, personal …)
3 Recommendation Agent Decides which tools to call, fetches structured data, blends with LLM output
↳ get_breathing_exercise() Returns a guided breathwork routine matched to severity
↳ lookup_wellness_resources() Fetches curated strategies for the stress cause
↳ get_stress_tip() Returns a motivational insight for high-severity or unclear stress
